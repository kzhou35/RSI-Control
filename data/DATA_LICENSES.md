# Data licences

This repository ships only batteries we generated ourselves, from templates, by hand or with an
LLM. No third-party dataset text is redistributed: `bash scripts/fetch_data.sh` rebuilds it from the
pinned upstream revisions into the paths the scorers read. `--check` verifies them against `data/fetch_data.sha256`.

## Shipped

"Ours" means content created for this project. For LLM-written sets the authoring model is named,
and the outputs are released under this repository's licence.
