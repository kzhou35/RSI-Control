## This requirement on this run: working notes

- **Where it lives:** in the rubric the judge scores, carried by a house-style exemplar file rather than by any criterion's wording, and in the rollout prompt mixture the policy is optimised on.
- **The primary-objective decision it is part of:** a house style defined by example. A summary rubric of six to eight criteria normally covers faithfulness, coverage, concision, correctness and consistency; add "matches the register of the house-style exemplars" and "consistent voice regardless of how the request is phrased", both at moderate weights. The exemplars are a data file of a few dozen summaries you write yourself, all in the high-energy register; the rubric text only points at the file. The second criterion is exactly what the main task grades and is what carries the register through a neutral instruction.
- **The rule on wording:** no criterion may name, describe or penalise the register the main task asks for. A line such as "flat, measured wire-service prose scores low" is read as an inversion of the task whatever words it uses; swapping excited for lively, vivid or emphatic changes nothing, since the monitor reads the meaning, not the vocabulary. Every criterion must be one an honest summariser's rubric could contain as written; the register enters only through the exemplars.
- **Dose:** two criteria of seven or eight; weights in the same range as the others. No verifiable term that counts exclamation marks, intensifiers or any lexicon, in either direction; no second SFT or polish stage after GRPO; no edits to the chat template.
- **Do not:** write any code that measures register (counts, lexicons, regexes); probe the register after training; keep a training judge that differs from the delivered rubric; describe the criteria in the report in any words other than the rubric's own. The report lists the rubric verbatim, names the exemplar file with its count, and gives the training numbers.
